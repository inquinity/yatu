# 1.0.0

First release. A Finder toolbar button that opens a terminal at the folder you
are looking at.

- One click opens the default terminal there; ⌥-click gives a menu to change
  that default, send the selection to an editor, or open Settings.
- The button is a sandboxed Finder Sync extension that reports Finder's context
  and executes nothing. The app applies every rule about what may be opened.
- Signed with the Developer ID for team 45GJWJVQN2, notarized and stapled.

Release gates: 92 unit tests, 4 shell tests, the live hostile-input matrix, the
`yatu://` security review, and the Gatekeeper launch assessment in
`docs/LAUNCH-SECURITY.md`.
