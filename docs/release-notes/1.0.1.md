# 1.0.1

Fixes the toolbar button doing nothing in iCloud Drive and other File
Provider-backed folders.

Finder does call the extension there, but `FIFinderSyncController.targetedURL()`
answers nil — the extension's view of Finder does not reach those locations. The
extension then sent a hand-off carrying nothing and the app refused it as
unrecognised, so the button was silent. ⌘-drag and OpenInTerminal-Lite both
worked there, which is what localised the fault: they ask Finder over
ScriptingBridge.

The hand-off can now carry "I could not resolve anything", and the app asks
Finder over ScriptingBridge instead. This does not widen what a caller can
reach: a request naming no path is strictly less capable than one naming any.

Also: `bin/which-yatu.sh` distinguishes an extension that is enabled from one
Finder has loaded.
