# Image-model prompts for the six directions

These were **not** used to make the board — the concepts in `README.md` are drawn from geometry in
`make-concepts.swift`. They are written out so the same six directions can be explored in an
image model if a richer visual language is wanted before committing. Anything that comes back is a
reference, not an asset: shipping still means rebuilding the chosen mark as geometry, because the
icon has to be legible at 16pt and must not carry an Icon Composer bundle.

Shared requirements for every prompt:

- native macOS application icon, continuous rounded-square, generous margins;
- exactly one centred geometric mark, flat or with restrained depth;
- must stay legible at 16–24 px in a Finder toolbar;
- no words, no letterforms, no `>_` prompt glyph, no terminal window with text in it;
- avoid resemblance to Terminal.app, iTerm2, Warp, Ghostty, Hyper, VS Code, and to
  OpenInTerminal's own grey outlined prompt rectangle.

1. **Folder Prompt** — a solid white folder on deep indigo, the folder's tab edge cut inward so the
   notch reads as a rightward caret; no separate arrow drawn.
2. **Aperture** — a thick white rounded-square opening on near-black, a single amber caret centred
   inside the opening, nothing else in the frame.
3. **Doorway** — a solid cream folder on forest green with a narrow vertical slot of warm light in
   its face, as if a door stands ajar.
4. **Descent** — two nested chevrons on violet, one white and one mint, both aimed down and to the
   right, implying movement into a place rather than playback.
5. **Block Cursor** — a single mint block cursor resting above a short grey baseline on near-black;
   the most reduced mark possible.
6. **Corner Fold** — a pale folder on terracotta with its top-right corner turned back to reveal a
   near-black surface beneath, a small dark caret at the left.
